# diplom
Репозиторий дипломной работы SkyPro
**Объект тестирования:**
- API: https://api.poiskkino.dev (бывший kinopoisk.dev) — REST API с данными о фильмах, сериалах, актёрах и режиссёрах
- UI: https://dashboard.poiskkino.dev/dashboard — управление API-ключом и тарифом

Ключевые функции для тестирования:
1. Поиск фильма по названию (fuzzy-поиск)
2. Получение карточки фильма по ID
3. Фильтрация фильмов по параметрам (жанр, год, рейтинг)
